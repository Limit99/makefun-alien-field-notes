# Three Stars for Earth

A tiny Node/TypeScript program for the make.fun bounty "Alien Field Notes: The Two Day Earth Review". It writes one alien tourist review of Earth to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> ★★★☆☆ Lovely gravity, excellent rain, but the locals queue politely for everything and then apologise to the queue. Would orbit again, mainly for the snacks.

Run it with: `node main.ts`
